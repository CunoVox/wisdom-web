# Wisdom

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Vietnamese learners discovering courses and studying online; instructors publishing lessons; managers and administrators operating the platform.

## Product Purpose
Discover, purchase or enroll in courses, then read or watch lessons and track learning progress.

## Capabilities and Constraints
Existing React/TypeScript frontend and Spring backend are the functional source of truth. Preserve authentication, role checks, category trees, learning, authoring, payments, uploads, rich text and operational controls. Course counts, ratings, images and prices must come from the API. No invented ratings, sales, certificates or testimonials. Public file visibility is accepted by explicit user choice.

## Brand Commitments
User approved a complete Edumim-inspired redesign, including mint/coral colors, while retaining the existing Wisdom logo and mascot. Public pages use a horizontal header with personal links in the avatar menu for every role; the workspace sidebar belongs only to staff/author work routes. Vietnamese interface with simple user-facing language. Administration has a separate task-focused layout.

## Evidence on Hand
`public/logo.png`, `public/icon.png`, existing routes/API contracts and test fixtures. The user approved the complete redesign on 05/10/2026 after reviewing the proposed page structure.
